# 실시간 주식 모의투자 경쟁 v5 (Node.js + localStorage, Render Free 호환)

## Render Free 배포 및 로컬 실행 방법
```bash
npm install
npm start
```
- Render.com Web Service(Free 플랜)에 배포할 때 Build Command는 `npm install`, Start Command는 `npm start`로 설정하면 됩니다.
- 서버의 파일시스템(`users.json`)을 사용하지 않으므로 Render Free 컨테이너가 슬립·재시작되어도 유저 데이터가 초기화되지 않습니다.

## 주요 기능
1. **브라우저 `localStorage` 영구 저장**:
   - 보유 현금, 누적 지급 원금, 마지막 접속 일자, 연속 출석 일수는 물론 **보유 주식의 종류(`국내주식`/`해외주식`), 종목명, 코드, 구매 가격(평단가), 보유 개수, 총 매수금액, 최근 거래 기록**까지 모두 브라우저 `localStorage`에 자동 저장됩니다.
   - 입장 시 및 재접속 시 `localStorage`의 데이터를 방 세션에 동기화하여 실시간 랭킹에 즉시 반영합니다.
2. **신규 가입 기본 지원금 1,000,000원 & 연속 출석 보상**:
   - 신규 닉네임 접속 시 기본 지원금 `1,000,000원`이 지급되며, 매일 출석 시 `10,000원`, `3일 연속 출석`부터 `20,000원(2배)`이 지급됩니다.
3. **실시간 랭킹 (수익률 / 총자산 토글 스위치)**:
   - 현재 방에 접속 중인 유저만 표시되며, 상단 스위치 버튼으로 **📈 수익률 순위**와 **💰 총자산 순위**를 즉시 전환할 수 있습니다.
4. **실시간 주식 시장 TOP 3 & 내 주식 관리 모달**:
   - 메인 화면에는 상위 3위 종목까지만 표시되며, 하단의 **[내 주식 관리]** 버튼으로 보유 주식 확인·매도 및 국내/해외 신규 주식 매수(스위치 전환, 랜덤 10개, 전체보기, 검색)를 이용할 수 있습니다.
